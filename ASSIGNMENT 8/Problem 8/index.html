Box-Sizing Comparison

Understanding Box-Sizing Property

Box-sizing controls how the total width and height of an element is calculated.

  • content-box (default): Width and height apply only to the content area.
  • border-box: Width and height include content, padding, and border.

Content-Box (Default)

Width: 200px

Padding: 20px

Border: 5px

Total Width: 250px

Border-Box

Width: 200px

Padding: 20px

Border: 5px

Total Width: 200px

CSS Code Example

.content-box {
    box-sizing: content-box;
    width: 200px;
    padding: 20px;
    border: 5px solid #333;
}

.border-box {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 5px solid #333;
}
