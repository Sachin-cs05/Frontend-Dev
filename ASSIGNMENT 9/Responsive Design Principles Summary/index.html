Core Principles of Responsive Design

Fluid Layouts

Fluid layouts use relative units like percentages instead of fixed units like pixels to define width and other properties.

.container {
  width: 90%;
  max-width: 1200px;
  margin: 0 auto;
}

Flexible Media

Flexible media ensures images, videos, and other media elements scale appropriately within their containing elements.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Breakpoints are screen widths that trigger changes in layout through media queries to optimize for different devices.

@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
