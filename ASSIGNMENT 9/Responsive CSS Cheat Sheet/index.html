Responsive CSS Cheat Sheet

Filters

CSS filters allow you to apply graphical effects like blur or color shifting to elements.

filter: blur(5px);
filter: grayscale(100%);
filter: sepia(100%);

Media Queries

Media queries modify the presentation of content based on device characteristics.

@media (max-width: 768px) {
  /* styles for tablets and mobile */
}

Responsive Design

Creating web pages that look good on all devices and window or screen sizes.

flex-wrap: wrap;
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Typography

Using relative units and functions for scalable, responsive text.

font-size: clamp(1rem, 2.5vw, 1.5rem);
line-height: 1.4;
