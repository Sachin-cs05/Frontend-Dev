Linear Gradient Section

This section uses a linear gradient background that transitions from blue to purple. The background is fixed, creating a parallax-like effect as you scroll through the page.

Linear gradients transition colors along a straight line. You can control the direction and color stops to create various visual effects.

Radial Gradient Section

This section uses a radial gradient background that radiates from the center. Radial gradients create circular or elliptical transitions between colors.

You can control the shape, size, and position of the gradient's center to achieve different visual effects. This example uses a circle shape with color transitions from yellow to orange to red.
