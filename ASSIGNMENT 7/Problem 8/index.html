Understanding the CSS Box Model

In CSS, the box model describes the rectangular boxes that are generated for elements in the document tree. Each box has four edges:

Content

Content

The content area where text and images appear.

Padding

Transparent area around the content inside the border.

Border

The edge surrounding the padding (if any) and content.

Margin

Transparent area outside the border, separating elements.
